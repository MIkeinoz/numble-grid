# Numble Grid

**Numble Grid** is a free browser-based Number Waffle helper and strategy trainer. It is designed to help players practise number placement, test moves, undo swaps, identify incorrect placements, and improve their approach to solving Number Waffle-style puzzles.

## Use Numble Grid

**Live app:** https://mikeinoz.github.io/numble-grid/

**How it works / strategy guide:** https://mikeinoz.github.io/numble-grid/guide.html

## What it helps with

- Recreate a puzzle in an interactive grid
- Test number placements before committing to a strategy
- Undo moves and work back through a solving sequence
- Identify incorrect placements
- Practise swap and cycle reasoning
- Build a more repeatable Number Waffle solving method

## About

Numble Grid is an independent, player-made learning and strategy tool. It is not affiliated with, endorsed by, or sponsored by Waffle Studio or the creators of Number Waffle. Product and game names belong to their respective owners.

The app runs directly in a modern web browser; no installation or account is required.
